# Rishab Shah | Resume website

My personal resume website, built with plain HTML and CSS for my Web Development course.

**Live site:** https://rishab-shah-mmvi.github.io/

## Files

| File | What it is |
| --- | --- |
| `index.html` | The page content |
| `style.css` | All the styling |
| `favicon.png` | The small icon in the browser tab |
| `og-image.png` | The preview image shown when the link is shared |
| `rishab-shah-resume.pdf` | A PDF copy of the page |

## Design

The page is laid out like an account ledger. Dates sit in a left margin, a red double rule separates them from the entries, and thin blue lines divide the sections.

- Fonts: Libre Caslon Display for headings and Public Sans for body text, both from Google Fonts
- Colours: off-white paper, navy ink, one red accent
- Layout: Flexbox for the navigation bar, CSS Grid for the cards, and media queries for tablets, phones and print
